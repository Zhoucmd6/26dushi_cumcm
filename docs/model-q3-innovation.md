# 问题3：可验证的建模创新方案

当前实施版本以 [model-q3.tex](./model-q3.tex) 为准：采用提前量条件场景与CVaR，不建立鲁棒优化、DRO或Tube MPC。

本文件是建模方案与推导笔记，不是论文正文，也不包含求解结果。建议以“结算规则下的不调整区间 + 预报误差条件校准 + 风险可控的随机滚动调度”为主线。MPC负责随着新信息更新计划，创新点放在信息如何进入调度、调整为何发生以及改进如何验证。以下方法均有既有研究基础，不能直接宣称为首次提出。

## 1. 信息、时间和费用先固定

物理调度采用10分钟时段，\(\Delta t=1/6\ \mathrm h\)，每天144个时段、145个储能状态点。预报更新时刻为 \(k\in\{0,6,12,18\}\ \mathrm h\)，两者不能混用。附件3是未来整点功率预报，先按登记的时间标签口径映射至10分钟平均功率，再乘 \(1/6\) 转为kWh。插值提高时间分辨率，不会增加真实预测信息，也不能从曲线形状“证明”标签含义。

日期 \(d\)、时刻 \(k\) 的信息集 \(\mathcal I_{d,k}\) 包含：截至该时刻可见的实际负荷、光伏与储能量；已经发布的预报；固定日内电价；0:00的原始购电计划。目标时段尚未结束的预测误差不能进入校准样本。未来6:00、12:00、18:00的预报在0:00不可见。

基本符号沿用项目约定：

- \(q_t\)：0:00制定的原始计划购电量。
- \(r_{t|k}\)：在更新时刻 \(k\) 对未来时段 \(t\) 制定的调整后购电量。
- \(c_{t|k},d_{t|k}\)：交流母线侧充、放电量。
- \(s_{t|k}\)：时段开始时储电量。
- \(e^\omega_{t|k},u^\omega_{t|k}\)：场景 \(\omega\) 下紧急购电量和富余电量。

上述量均为kWh，只有 \(s\) 是时刻库存，其他都是10分钟时段电量。电价 \(p_t\) 为元/kWh。

主结算假设沿用A7：

\[
g_t(q_t,r_t)
=p_tq_t+1.5p_t(r_t-q_t)^+-0.5p_t(q_t-r_t)^+
=p_tr_t+0.5p_t|r_t-q_t|.
\]

这相当于按最终购电量付款，并对偏离原计划的电量支付50%的违约费用。它是对题面措辞的一种解释，须同时保留“原计划全额照付、下调另罚50%”的备选口径。多次调整按最终执行量相对0:00计划一次结算；不能把6:00、12:00、18:00优化时的目标值相加充当实际账单。

题目没有提供固定的单次调整费、预报购买费或并网出售收益，不将这些假想参数放入主模型。

## 2. 最值得推导的性质：结算规则产生不调整区间

先用一个简化模型解释调整行为。只看一个时段，忽略储能耦合，假设外网需要承担的随机净负荷 \(N\geq0\)，条件分布为 \(F(n)=\Pr(N\leq n\mid\mathcal I_{d,k})\)，电价 \(p>0\)。原计划 \(q\geq0\) 已定，选择调整量 \(r\geq0\)：

\[
\min_{r\geq0}\quad
J(r)=pq+1.5p(r-q)^+-0.5p(q-r)^+
+5p\,\mathbb E[(N-r)^+\mid\mathcal I_{d,k}].
\]

假设分布连续且有关分位数唯一。在 \(r<q\) 与 \(r>q\) 两侧分别求导：

\[
J'(r)=
\begin{cases}
0.5p-5p[1-F(r)],&r<q,\\
1.5p-5p[1-F(r)],&r>q.
\end{cases}
\]

两段均为凸函数，在 \(r=q\) 处导数向上跳变。令
\(a=F^{-1}(0.7)\)、\(b=F^{-1}(0.9)\)，其中
\(F^{-1}(\tau)=\inf\{n:F(n)\geq\tau\}\)，得到

\[
r^*=
\begin{cases}
a,&q<a,\\
q,&a\leq q\leq b,\\
b,&q>b.
\end{cases}
\]

解释如下：

1. 原计划低于70%分位数时，上调至70%分位数。
2. 原计划落在70%至90%分位数之间时，保留原计划。
3. 原计划高于90%分位数时，下调至90%分位数。

这些百分比是给定倍率和结算假设下的解析结果，不是附件计算结果，也不表示可靠性承诺。离散场景用次梯度与分位数集合处理，可能存在多个最优解；净负荷允许为负时还需结合 \(r\geq0\) 的边界。

它与问题2的80%分位数相呼应：问题2提前购电边际成本为 \(p\)，问题3在原计划两侧的边际成本分别为 \(0.5p\) 和 \(1.5p\)。因此“收到新预报就把购电量改成新均值”没有经济依据。

这条性质是本题可以独立推导和检验的结构结论，尚不构成学术首创声明。实际电池将不同时段耦合起来，不能逐时机械套用70%和90%；可将其作为无储能基线、优化结果解释以及求解初始化。完整模型中的储能边际价值会改变有效调整边界。

**结算歧义对结论的影响。** 若下调解释为在原计划已全额付费后再加 \(0.5p(q-r)^+\)，则 \(r<q\) 时导数变成
\(-0.5p-5p[1-F(r)]<0\)。在当前允许无成本富余处置的简化模型下，下调不会更优。应据此检查结算解释是否使题目中的下调机制退化，而不能在两个结算口径下复用70%—90%区间。

## 3. 推荐主模型：条件场景与风险可控的随机MPC

### 3.1 先校准官方预报，再生成条件场景

附件3已经给出预报。第三问首先利用这些预报，第二问的历史平均、SARIMA或树模型可继续用于负荷预测、预报偏差校正或缺省基线。

以功率残差为例，历史目标时段 \(t\) 相对发布时刻 \(k\) 的误差为
\(\epsilon^G_{j,k,t}=P^{G,\mathrm{real}}_{j,t}-\widehat P^G_{j,t|k}\)。
按照发布时刻、预测提前量、日内时刻及样本允许的季节分组，估计偏差和残差分布；不能先验断言越晚的预报必然更准。

对截至 \(\mathcal I_{d,k}\) 已经验证的历史残差，进行同一历史日的负荷与光伏联合块抽样；样本不足时合并相邻提前量组。保留时段间相关性，不能把144个点当成独立样本。修正后的光伏保持非负，夜间约束来自当时可用的日历或历史规律；高频误差要从历史10分钟数据校准，不能用小时插值假装捕捉了高频波动。

还可以令 \(\widetilde P^G_{t|k}=\widehat P^G_{t|k}+b_{k,\ell}\)，\(\ell\) 为预测提前量，校准参数 \(b\) 的单位为kW。为防止只有1月历史时过拟合，应先采用少量提前量分组和收缩估计。

### 3.2 决策导向校准

借鉴Smart “Predict, then Optimize”的思路，采用历史样本外调度费用选择偏差校正、场景尺度或候选模型，而不是仅按RMSE选择。

\[
\theta_d^*\in\arg\min_{\theta\in\Theta}
\sum_{j\in\mathcal V_d}
F_j^{\mathrm{real}}\bigl(\text{按当时信息执行的策略}_\theta\bigr),
\qquad \max\mathcal V_d<d.
\]

这里 \(\theta\) 是少量校准参数；\(\mathcal V_d\) 是预测日之前的验证日期，各验证日也必须只使用其更早数据训练。实际评价日期 \(d\) 不能用于挑选自己的参数。参数选择依次做内层时间验证、外层滚动测试。

该方案是“基于决策费用的校准”，并未声称实现端到端可微训练。原始SPO论文主要讨论目标成本向量预测，本题负荷/光伏进入平衡约束的右端，不能直接照搬SPO+损失及其理论保证。来源：[Elmachtoub与Grigas](https://arxiv.org/abs/1710.08005)，期刊版2022年，本地公开稿为2020年修订版。

### 3.3 风险度量与优化结构

给定更新时刻 \(k>0\)，剩余时段集合为 \(\mathcal T_k\)，所有 \(t\in\mathcal T_k\) 的公共计划为 \(r,c,d,s,z\)，场景补救为 \(e^\omega,u^\omega\)。定义剩余紧急购电费用

\[
C_k^\omega=\sum_{t\in\mathcal T_k}5p_t e^\omega_{t|k}.
\]

基准目标是最小化期望费用；风险增强版采用

\[
\min\quad
\sum_{t\in\mathcal T_k}g_t(q_t,r_{t|k})
+\sum_\omega\pi_\omega C_k^\omega
+\lambda\left(\zeta+
\frac{1}{1-\alpha}\sum_\omega\pi_\omega v_\omega\right)
+\Phi_{d,k}(s_{\mathrm{end}|k}),
\]

\[
v_\omega\geq C_k^\omega-\zeta,\quad v_\omega\geq0,
\quad \zeta\in\mathbb R,\quad 0<\alpha<1,\quad \lambda\geq0.
\]

\(\zeta,v_\omega,C_k^\omega,\Phi\) 的单位为元，\(\lambda,\alpha,\pi_\omega\) 无量纲。括号中是CVaR的场景线性化，表示费用分布高损失尾部的平均风险；离散分布含分位点原子时不能简单替换为条件期望。可先比较 \(\lambda=0\) 和少量正值，\(\alpha=0.9\)或0.95只是待校准候选。

物理约束仍为

\[
r_{t|k}+e^\omega_{t|k}+G^\omega_{t|k}+d_{t|k}
=L^\omega_{t|k}+c_{t|k}+u^\omega_{t|k},
\]

\[
s_{t+1|k}=s_{t|k}+0.9c_{t|k}-d_{t|k}/0.9,
\quad1200\leq s_{t|k}\leq10800,
\]

\[
0\leq c_{t|k}\leq(5000/6)z_{t|k},\quad
0\leq d_{t|k}\leq(5000/6)(1-z_{t|k}),\quad
z_{t|k}\in\{0,1\},
\]

以及 \(r,e^\omega,u^\omega\geq0\)、当前真实储电量作为初始值和已登记的跨日终端条件。\(g_t\) 可以用偏差正负变量线性化，\(\Phi\) 取已知线性或凸分段线性函数，得到MILP；删除充放电二进制限制后的对照为LP。

0:00使用 \(q\) 作为购电决策，购电费用为 \(\sum p_tq_t\)，随后各时刻固定这个原始 \(q\)。在6小时更新之间执行已经选定的储能时段计划，10分钟误差由紧急购电与富余处置响应；每次更新只执行到下一次更新，再以真实状态重算。因此这是采用两阶段近似的随机滚动策略，尚未全面优化未来预报更新的期权价值。若提前联合优化将来更新，须建立预报发布的情景树。

若进一步允许电池每10分钟适应新观测，则需单独定义因果反馈或短时MPC；不能给每条完整场景任意配置一条提前知道未来的储能轨迹。

CVaR是主动增加的风险偏好，不是题目硬性要求。必须独立报告期望费用/实际总账单和尾部费用；降低尾部风险可能提高平均费用。不能把风险加权目标值当成真实电费，也不能声称电池备用保证零紧急购电。基础方法来源：[Rockafellar与Uryasev](https://sites.math.washington.edu/~rtr/papers/rtr179-CVaR1.pdf)。

## 4. 信息价值：直接回答是否需要其他预报时刻

题目提供的日内候选更新时间为 \(\{6,12,18\}\)。除0:00必须使用外，可比较其全部 \(2^3=8\) 个子集，而不只比较四个依次增加时刻的子集。这样也覆盖“只用12:00”或“跳过12:00但使用18:00”等组合。

设 \(J(B)\) 为在同一评价期内，允许使用时刻集合 \(\{0\}\cup B\) 的策略实际购电费用，则

\[
\Delta V(k\mid B)=J(B)-J(B\cup\{k\})
\]

是加入时刻 \(k\) 的样本外经济改变量，单位为元。需报告逐日配对差值，保持各方案从相同初始状态独立连续运行；不能把一个方案每天的储电量强行赋给另一个方案。

严格区分三件事：收到新预报、重新求解、实际改变购电量。完整优化可以收到预报但选择不调整，故在模型正确、分布一致、信息免费、允许忽略信息及策略集合嵌套时，更丰富的信息不会提高理论最优期望费用。实际回放出现负的 \(\Delta V\) 时，应检查预报校准、有限样本、滚动近似或求解误差；不能据此推出“信息本身有害”。

经济触发可以定义为：在相同最新信息集、相同评价时域和未来决策权下，比较冻结本次外网计划与允许本次调整的最小预计成本

\[
\widehat B_k=J_k^{\mathrm{keep}}-J_k^{\mathrm{adjust}}\geq0.
\]

两者都允许同样的电池重新优化，差别仅在本次能否改变外网计划。调整费用已经计入目标，不再重复减去。没有固定调整费时，主模型的触发门槛为0；设置正门槛只能作为抑制估计噪声或减少求解/操作的算法参数，不能虚构为题目费用。

如果每次先完整求两个问题再触发，并未节约优化计算。要主张计算优势，必须使用便宜的分位数筛选或LP灵敏度近似，并统计筛选和重优化的总耗时。本题每天只有3次额外预报，事件触发的计算优势未必显著，适合作为辅助而非唯一创新。相关研究：[Wu等，2022，事件触发微网电动汽车管理](https://doi.org/10.1016/j.jclepro.2022.133175)，目前仅核对出版页摘要，其电动汽车模型不直接适用于本题。

附件未提供3:00、9:00等额外时刻的官方预报，不能给这些时刻编造“实证节省率”。可以依据已有提前量误差建模做明确标注的假设性仿真，或在额外时刻重新校准既有预报；后者是增加内部计算更新，不等于获得新的官方信息。

## 5. 当前范围收敛

按用户最新要求，本次不建立动态备用、Tube MPC、鲁棒优化或DRO；原已下载资料保留作历史索引，不作为当前必学内容。

新增主线为预测提前量条件尺度与归一化可信度，详见独立LaTeX第4节。指数候选必须与常尺度、分箱尺度比较；它不是真实概率，也不应直接折扣光伏均值。

## 6. 模型选择与验收

建议首先比较：

| 方案 | 新增内容 | 要验证的贡献 |
|---|---|---|
| B0 | 第二问日前计划，日内不修订 | 衡量日内预报的整体价值 |
| B1 | 官方点预报 + 确定性MPC | 充分可行的基础对照 |
| B2 | 按提前量校准的联合场景 + 随机MPC | 不确定性建模是否改善费用 |
| B3 | B2 + 基于历史决策费用的校准 | 决策导向是否优于只按RMSE校准 |
| B4 | B3 + CVaR | 平均费用与极端紧急购电风险的交换 |
| 尺度对照 | 常尺度、指数尺度、分箱尺度 | 检验提前量指数是否适配 |

70%—90%不调整区间作为无储能解析对照单独检验，不机械强加到完整模型。各次只增加一个机制，避免无法判断收益来源。

验收要求：

- 评价期按2025-02-01至12-31逐日滚动，共334天；所有方案采用相同账单口径、信息权限、初始与终端政策及时间对齐方式。
- 相同官方预报、相同场景样本与求解容差下比较调度层；单独比较校准层时明确改变了哪些参数。
- 不预先选择最有利日期；报告全年总费、月度表现、实际紧急购电kWh、95%尾部紧急费用、调整kWh及次数、富余kWh、电池吞吐与运行时间。
- 每10分钟满足能量平衡、储能边界和功率边界。紧急购电可以维持供需平衡，因此紧急购电不是未供电量。
- 样本外按日配对比较，置信区间采用保持相邻日期相关性的块抽样；不把单个10分钟点当成独立重复试验。
- 8种更新时间组合属于信息价值实验。若要选出上线方案，应只用过去日期选择组合，再在未来日期验证；全年事后最佳组合只能称回顾性对照。
- 对效率、下调结算、风险权重和终端价值做敏感性检查。终端价值只用于优化，不能加入实际购电账单。
- 使用同样约束与结算规则的完美信息结果仅作下界，不能假装成可执行模型。

当前推荐完成B1—B4的建模定义和不调整区间推导，检验指数尺度是否优于常尺度或分箱，不增加DRO。奖励等级不能由算法名称预测；方案的优势需要来自题意对应、结构推导、无泄漏验证和清楚的费用解释。
