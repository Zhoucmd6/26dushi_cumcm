# 第四问实质修订说明

本版不仅调整来源表述，而是改变Q4-2的费用估计和Q4-3的条件决策结构。详细变量、公式、取值域和推导见 [LaTeX模型](model-q4.tex)，阅读版见 [PDF](model-q4.pdf)。当前未运行求解、未提供节省率。

## 新旧模型差异

| 部分 | 旧版 | 本次实质修改 |
|---|---|---|
| Q4-2价量依赖 | 完全使用历史成对样本 | 联合分布与同边际独立分布按rho混合，过去验证选rho，缓解小样本依赖估计过强 |
| Q4-3日前计划 | 0点按共同全天动作优化，到6点才重排 | 0点就联合选择原始购电承诺、当前动作和下一更新后的条件调整方案 |
| 储电量 | 由当前共同剩余计划决定 | 各未来信息组从同一桥接库存出发，其后续最优费用反过来影响当前应留多少电 |
| 未来信息 | 当前场景中所有电池动作共同 | 当前块共同，下一发布节点之后允许同组共同动作；组号只用届时可观测信号 |
| 规模与验证 | 一套剩余时域动作 | 只展开下一次更新、1至3组；K=1应恢复旧版，不建立庞大全日情景树 |

直观地说：旧版先做一份全天计划，收到新信息再补改；新版在制定计划时就比较“下一次收到不同信息时，我分别能怎样改”，并据此选择现在购电和储电。并没有提前知道下一次实际收到什么信息。

## 两项改进的边界

- rho只在历史滚动验证中选择，不能由当天优化器自由挑选，也不等于相关系数或预测正确概率。应急项仅替换线性系数，实际账单仍用真实电价。
- 下一节点信号为新旧官方光伏预报修订，以及节点前一小时的已实现价格偏差。当前只能用历史配对样本模拟它，不能读取当天未发布预测或未来实际价量。
- 全部组在分叉前共享动作与同一个库存；只有更新后行动可随组变化。应急补救在更新前后逐时发生，这是截断多阶段近似，不是把全部补救推到日末的严格两阶段交易。
- 每日仍在0、6、12、18点优化，只执行当前6小时。18点不再展开当日下一节点。原物理约束、10分钟粒度和结算假设不变。
- 主版Q4-2研究收缩，Q4-3研究分组前瞻，不同时叠加两项改动、复杂预测器和CVaR，便于辨认收益来源。

## 文献来源与本题设计

Li等（2016），*Flexible Operation of Batteries in Power System Scheduling With Renewable Energy*，[公开全文](https://www.mcs.anl.gov/papers/P6089-0416.pdf)，第II-A、II-D节提供分桶非预见性和储能灵活运行启发。本题的信息信号、原始承诺结算、桥接库存和单次更新前瞻另行定义，不照搬机组组合或备用市场。

Q4-2混合收缩是本题候选设计；Elmachtoub与Grigas的决策导向思想仅支持按历史调度费用选择参数，不为该公式或效果提供现成保证。全部来源定位见 [文献索引](../literature/README.md) 的07、14号。

## 优先交给团队验证

1. rho=0恢复独立模型，rho=1恢复成对模型；混合权重和及单位正确。
2. K=1在相同场景、终端与结算下恢复旧版最优目标；K>1能够嵌入旧共同动作方案。
3. 同组动作一致，全部组桥接库存一致；分组映射可在真实下一更新时计算，不泄漏未来。
4. 场景展开与组内条件H函数形式一致；LP净化不改变库存或破坏组内共享。
5. 用同日期、相同控制机会和各自连续库存做样本外账单比较；不以优化器预测目标变小代替真实收益证据。

若新增方法没有稳定样本外收益，退回rho端点或K=1是合理的模型选择，不为“创新”保留无用复杂度。
