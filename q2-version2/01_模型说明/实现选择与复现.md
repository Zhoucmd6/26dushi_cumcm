# 实现选择与复现

主入口为 `02_计算工程/src/run_v2.py`，配置为 `configs/q1_q2_v2.json`。P1/P2/P3、残差抽样、1月验证、固定日前策略及终端处理的完整说明见[正式报告](../03_结果/前两问version2模型落实与求解报告.md)。数值核心保持正式运行的原始字节，核验依据为 `04_复核记录/full_v2_20260912/run_manifest.json`。

## Python数值计算

在 `02_计算工程` 目录执行；建议Python 3.13及独立虚拟环境。正式运行环境另存于复核目录。

```powershell
python -m pip install -r requirements.txt
$env:PYTHONIOENCODING='utf-8'
$env:PYTHONDONTWRITEBYTECODE='1'
$env:OPENBLAS_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
$env:MKL_NUM_THREADS='1'
python -m unittest discover -s tests -v
python src/run_v2.py --run my_v2_pilot --pilot
python src/audit_v2.py outputs/my_v2_pilot
```

小样例包含1月预热、验证及2月前3天的14组实验，不能作为全年结果交付。正式运行使用新的名称：

```powershell
python src/run_v2.py --run my_v2_full
python src/audit_v2.py outputs/my_v2_full
python src/prepare_v2.py outputs/my_v2_full
python src/report_v2.py outputs/my_v2_full
```

每次新运行写入 `outputs/`，不覆盖 `03_结果` 的正式交付。数值代码、配置或输入哈希发生变化时，不复用旧运行名。完整求解较慢；归档仅保留审计摘要，不能将它当作含全部中间文件的可恢复运行目录。

数值计算只读取 `data/processed/actual_points.csv` 和 `baseline_points.csv`，已包含于本包。原始附件1/2及结果模板不新增上传。`src/prepare_local_inputs.py` 可从仓库已有原始附件目录复制所需文件，并检查其SHA256：

```powershell
python src/prepare_local_inputs.py
# 单独下载本子目录时，指定包含“附件1.xlsx、附件2.xlsx、附件5”的附件目录：
python src/prepare_local_inputs.py --raw-dir 'D:/资料/附件'
```

文件复制到被git忽略的 `data/raw/附件`；仅用于输入留档和Excel模板导出，不会覆盖不一致文件。缺失原始附件不影响使用现有规范化CSV求解。

## Excel导出

先完成 `prepare_v2.py`，再运行以下命令。需要安装Codex提供的Node运行时与 `@oai/artifact-tool`；此专用依赖不由requirements安装。未配置该环境时，可直接查看已交付的Excel或重新计算CSV。

```powershell
./导出Excel.ps1 -RunDirectory outputs/my_v2_full -PythonExecutable python
```

`run_pipeline.py`、`reporting.py` 和旧版配置为回归测试兼容保留，不是本版主入口。`precompute_v2.py` 是可选预计算入口；串行主程序也能复现。`finalize_v2.py` 供完整导出与图形检查结束后的原流程归档使用，不是数值求解必需步骤。旧版独立Excel导出器及其历史快照已移出。

## 论文口径

时间统一为00:00—24:00，源标签视为区间终点；保持原点序。终端价值不计入现金费用，总未利用电量不等于全部付费购电浪费。主方案333天末端贴上限是已披露的局限，不能解释为已解决跨日价值问题。
