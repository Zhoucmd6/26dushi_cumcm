# 2026 国赛论文写作与验收指南

## 一 官方硬性要求

依据全国大学生数学建模竞赛组委会 2026 年修订稿：电子版论文必须是单独的 PDF 或 Word 文件，建议 PDF，大小不超过 20 MB；电子版不得含承诺书和编号专用页，第一页必须是摘要专用页。纸质版使用 A4 纸，四边页边距至少 2.5 cm。摘要含标题和关键词原则上不超过一页，从摘要页起在页脚中部连续编号。正文不要目录且不超过 30 页，附录页数不限。引用必须在正文标注并列入参考文献，全文不得出现参赛者、学校或赛区身份信息。

2026 年还要求：在参考文献之前设置“AI工具使用声明”；若使用 AI，应在支撑材料中提交 PDF 格式的 `AI工具使用详情.pdf`，列明工具名称或型号、使用环节、主要提示方式、采纳与人工核验情况。核心建模与分析须由参赛队主导，所有 AI 参与内容须逐项人工审查。

## 二 获奖导向

官方将假设合理性、建模创造性、结果正确性和文字表述清晰程度列为主要评奖标准。落实到本题，应优先做好以下事项：

1. 摘要直接回答四问。每问写“方法、关键处理、核心结果、结论”，避免只罗列算法名。
2. 先画信息时间线，再写优化模型。任何提前使用未来真实负荷、光伏或电价的方案只能称为完美信息下界。
3. 所有功率先乘 `1/6 h` 转为时段电量；严格区分 144 个流量时段与 145 个储能状态。
4. 创新必须可验证。第三问的提前量尺度、可信度指标和 CVaR要通过消融及样本外检验，不能把候选公式写成公认定律。
5. 结果章节同时给出经济性、物理可行性、预测误差和求解可靠性；所有百分比注明比较基准。
6. 图表服务于结论。每图只回答一个核心问题，单位、统计区间、数据来源和是否平滑必须清楚。
7. 主动呈现限制。第二问的333个正式日日末储量贴近上限，第三问90%区间覆盖率仅80.67%，第四问若干费用差额区间跨0，均应如实解释；不同权限、初始库存和预测器不同，不能直接作单变量归因。
8. 论文、附件结果表、代码输出和支撑材料必须可逐项对账。评审看到的每个结果都应能追溯到固定配置和源程序。

## 三 推荐结构

1. 摘要与关键词
2. 问题重述
3. 问题分析
4. 模型假设
5. 符号说明
6. 数据处理与公共物理模型
7. 问题一模型、求解与结果
8. 问题二模型、求解与结果
9. 问题三模型、求解与结果
10. 问题四模型、求解与结果
11. 模型检验、敏感性与评价
12. AI工具使用声明
13. 参考文献
14. 附录与支撑材料清单

## 四 终稿验收

- [x] 摘要页为 PDF 第一页，无目录。
- [x] A4、四边 2.5 cm、页脚中部阿拉伯数字。
- [x] Q1、Q2 的数字全部来自正式成果说明和结果文件。
- [x] Q3 已写入正式结果、消融、概率检验和预报时刻价值，并保留负结果与边界。
- [x] Q4 已写入价格预测、依赖收缩、条件前瞻、全年结果、指定日期和独立审计。
- [x] 数据图均保留 PNG 与 SVG；结构图保留 TikZ 源码。
- [x] AI 声明位于参考文献之前，并另建使用详情源稿。
- [ ] 三名队员完成逐项人工核验并确认AI使用详情与实际记录一致。
- [x] 已用四问正式结果重写摘要、结论与模型评价。
- [x] 最终附录加入完整可运行源程序及支撑材料说明。
- [x] 最终 PDF 小于20 MB，正文30页，附录从第31页开始。
