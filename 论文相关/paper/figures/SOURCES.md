# 图表来源与可编辑文件

本目录中的六组 PNG 与 SVG 均为 `04_正式成果/figures/` 中科研版图表的原样副本，视觉版本为 `academic_v2_20260912`。数值来自固定运行 `full_20260911T130000Z_9942ba59`；复制过程不重新拟合、不重新求解，也不改变图表内容。

| 论文文件名 | 原始图名 | 数据性质 |
|---|---|---|
| `data_overview.*` | C题数据概览 | 附件描述统计 |
| `q1_dispatch.*` | 第一问调度 | Q1正式求解结果 |
| `q2_comparison.*` | 第二问方法对照 | Q2四方案全年对照 |
| `q2_selected_days.*` | 第二问指定日期 | 四个指定日轨迹 |
| `q2_sensitivity.*` | 第二问灵敏度 | 四组全年重新回放 |
| `q2_heatmap.*` | 第二问全年调度热力图 | 334天完整轨迹 |

PNG用于稳定编译，SVG保留可编辑文字与矢量对象。`source/model_framework.tex` 是论文新增的TikZ结构图源文件，仅表达模型逻辑，不承载数值结果。
