# 架构图与变量口径

来源：用户于2026年9月11日提供的微网概念架构图，原样保存在references/微网概念架构图.png。已结合前两问修订稿补充总富余U；最新实现决定见《当前确认事项与代码进度.md》。

## 图的含义

微网母线是电能汇集和分配的连接点，本身不作为储能设备。外部电网和光伏向母线供电；母线向负载供电并可给电池充电；电池也可向母线放电。无法利用的光伏可记为弃光。图中未包含向外部电网售电的路径。

| 符号 | 含义 | 本说明采用的计量口径 | 建议的代码名称 |
|---|---|---|---|
| Q_t | 计划购电量 | 时段内依照购电计划实际送达母线的电量；第三问需分开保留原计划和调整后计划 | grid_plan_kwh；grid_scheduled_kwh |
| E_t | 紧急购电量 | 实际运行时补充送达母线的电量 | grid_emergency_kwh |
| G_t | 光伏电量 | 当前时段可用、扣除弃光前的光伏电量 | pv_available_kwh |
| L_t | 负荷用电量 | 当前时段小区需要得到的电量 | load_kwh |
| C_t | 充电量 | 母线送往电池、尚未扣除充电损耗的电量 | charge_bus_kwh |
| D_t | 放电量 | 电池向母线实际输出、已扣除放电损耗的电量 | discharge_bus_kwh |
| S_t | 储电量 | 时段t开始时电池内部存量 | stored_energy_start_kwh |
| W_t | 弃光量 | 当前时段未利用的光伏电量 | pv_curtailed_kwh |

Q、E、G、L、C、D、W是时段累计电量；S是一个时刻的储电状态。这里均使用kWh，不与附件中的kW功率直接相加。若模型选择不同的充放电计量侧，应修改本表、状态方程和结果导出口径，保持一致。

## 两条不同的平衡关系

第一问没有紧急购电，母线电量平衡为：

Q_t + G_t + D_t = L_t + C_t + W_t，其中W只表示弃光。

第二问固定日前充放电基线中，平衡为：

Q_t + E_t + G_t + D_t = L_t + C_t + U_t，其中U是所有来源的总未利用电量，不能一概称为弃光或已付费浪费。

电池内部状态更新为：

S_(t+1) = S_t + eta_c × C_t − D_t / eta_d。

如果建模手采用充电效率、放电效率分别为90%的解释，则eta_c = eta_d = 0.9。图本身没有确定效率数值或5000 kW限制的计量侧。

例如，C=100 kWh意味着母线支出100 kWh，按90%充电效率，储量增加90 kWh；D=90 kWh意味着母线得到90 kWh，按90%放电效率，储量减少100 kWh。效率只放在适用的状态关系中，不能再对母线侧C、D重复折算。

## 弃光与多余外购电需要区分

图上W明确标为“弃光量”。如果采用严格的弃光定义，应有0 <= W_t <= G_t，实际利用光伏为G_t−W_t。W不能同时默默代表电池损耗或所有来源的剩余电量。

修订稿第二问将未利用电量统一计入U，并对全部Q计费，已在固定计划基线代码中采用。若需要在论文中分别报告弃光和未利用外购电，仍需增加来源分配规则，不能只凭U推断。

## 第三、四问的扩展

保留零点原计划Q_plan、每次发布时刻可用的预报、调整记录和最终生效的购电计划Q_scheduled。实际电量平衡只使用该时段生效且交付的购电量；不要将原计划与完整的调整后计划相加。若调整变量表示增减量，应先按规则转换为最终生效电量。

原计划和调整记录分别用于计算合约费用、调增费用和调减费用。物理平衡与费用结算分开实现；图没有确定调减退款和多次调整的计费规则。

## 预测与实际运行

规划阶段使用预测负载和预测光伏；实际执行阶段使用当时已观测到的实际值，并根据既定控制规则决定可调整量和紧急购电。两者虽然共用拓扑，但必须保留预测/实际标识，不能把未来实际值填回零点决策。

## 后续独立检查

- 母线平衡残差：Q_delivered + E + G + D − L − C − W，单位kWh。
- 储量更新残差：S_end − S_start − eta_c×C + D/eta_d，单位kWh。
- 题设储量上下界及期初、期末与跨日约束。
- 在确定计量侧后，检查充放电功率限制。
- 按W的最终定义检查弃光范围。
- 分别检查物理购电量和费用台账，不要求两者在有违约/退款时简单等同。

残差容许范围需按求解器精度和单位设置，不应对浮点数直接要求逐位相等。
