# 第三问：代码与论文成果

这是精简后的第三问交付目录。主模型为PDF允许的B3分箱条件尺度随机滚动调度，B4在同一个B3上加入CVaR。

|目录|内容|
|---|---|
|q3-01_使用说明|复现指南、变量口径、绘图规范|
|q3-02_题目与模型|C题题面、建模手第三问PDF、概念图|
|q3-03_计算工程|必要源码、20项测试、参数、第三问原始数据和预处理数据|
|q3-04_正式成果|提交表、论文报告、科研图、执行轨迹和精简指标|
|q3-05_复核记录|最终审计与测试摘要，不含历史版本和运行缓存|

论文手先看 [模型报告](q3-04_正式成果/第三问模型核验与求解报告.md)、[公式对应](q3-04_正式成果/PDF与代码逐项对应.md) 和 [指定日期表](q3-04_正式成果/题目指定日期表格.md)。程序复现见 [使用指南](q3-01_使用说明/第三问复现与文件指南.md)。

主方案2—12月费用为16,627,713.37元。21组全年实验包含20种不同策略，20项测试通过。主方案是分箱尺度，不应写成指数衰减模型；R不是正确概率。

## 上传Git

上传本目录即可；不附带旧版本、依赖目录、检查点和运行缓存。根目录.gitignore用于Git客户端忽略后续生成的文件。网页“Upload files”不会替你应用本机.gitignore，应避免选择重新生成的node_modules和outputs。

精简仅调整交付内容，正式数值、源码模型和原始模型PDF未改。完整日内计划版本、逐点R及逐日场景诊断可由源码重新生成；保留的10分钟执行轨迹用于复核实际调度。不要把05摘要目录当作可断点续算的完整运行目录。
