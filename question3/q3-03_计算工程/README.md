# 第三问计算工程

主入口：src/run_q3.py。完整命令见 [复现指南](../q3-01_使用说明/第三问复现与文件指南.md)。

- src：求解、校准、验证、导出和科研绘图代码。
- tests：20项测试。
- data：附件1/2/3、result3模板和直接使用的三个预处理CSV。
- configs：已交付实验的参数与选择记录，供核对，不作为可随意修改的运行输入。

从头计算使用新的outputs目录；数值代码未因交付精简而修改。旧运行哈希记录包含当时一并存档、但第三问不读取的附件4和其它题模板。它们已从精简包移除，新计算会登记当前输入集的哈希，不应尝试续跑旧缓存。

Excel导出需要本机配置的Node与@oai/artifact-tool；node_modules不分发，必要时运行连接本机Excel依赖.ps1重新创建本机联接。该辅助脚本依赖当前电脑的安装位置。
